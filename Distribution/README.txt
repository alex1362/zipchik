ЗИПЧИК / ZIPCHIK 0.2.2 (preview)

1. Перетащите «Зипчик» в Applications.
2. Обычный архив: выделите в Finder и нажмите пробел.
3. Парольный или многотомный: Finder → «Открыть с помощью» → «Зипчик».

Требования: Apple Silicon (arm64), macOS 14+.
Эта preview-сборка пока не notarized: macOS может запросить явное подтверждение первого запуска.

---

1. Drag Zipchik to Applications.
2. Ordinary archive: select it in Finder and press Space.
3. Password-protected or multi-volume archive: Finder → Open With → Zipchik.

Requirements: Apple Silicon (arm64), macOS 14+.
This preview build is not notarized yet, so macOS may ask for an explicit first-launch confirmation.
