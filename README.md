# Зипчик / Zipchik

[English](README.en.md) · [Лицензии и уведомления](NOTICE.md)

Техническое имя проекта и bundle identifier пока сохраняют `ZIP`, чтобы не сбросить уже настроенные Finder-ассоциации и Quick Look. Отображаемое имя приложения локализовано: «Зипчик» на русском, Zipchik на английском.

macOS-приложение для просмотра содержимого архивов и выборочной распаковки.

Языки интерфейса: русский и английский; используется язык macOS.

Требования: только Apple Silicon (arm64), macOS 14 или новее.

> Статус: preview. DMG пока ad-hoc подписан и **не notarized**. macOS может предупредить при первом запуске на другом Mac; это будет устранено отдельным этапом notarization.

## Установка

1. Скачайте `Zipchik-0.2.2-arm64.dmg` из [Releases](https://github.com/alex1362/zipchik/releases).
2. Перетащите «Зипчик» в `Applications`.
3. Для обычного архива выделите его в Finder и нажмите пробел. Для парольного или многотомного — выберите «Открыть с помощью → Зипчик».

Если macOS заблокирует preview-сборку, откройте приложение из Finder с зажатой Control и подтвердите «Открыть». Это следствие отсутствующей notarization, а не просьба отключать защиту системы целиком.

## Интерфейс v0.2

- Основной интерфейс — предпросмотр Finder по пробелу: список файлов, чекбоксы и выборочная распаковка.
- Основное приложение не появляется в Dock и не имеет стартового окна. Оно открывает служебное окно только при явном «Открыть с помощью → Зипчик» для парольного или многотомного архива.
- В служебном окне остаются обновление (`⌘R`), выборочная распаковка (`⌘E`), пароль и работа с томами.
- Зашифрованный архив открывается через нативный `SecureField`. Пароль не записывается ZIP и живёт лишь в оперативной памяти текущего сеанса. Из-за интерфейса 7zz он кратковременно передаётся аргументом его дочернему процессу, но не выводится приложением в интерфейс или логи.
- Поддержаны многотомные наборы при открытии первого файла `.001`; ZIP подсказывает держать все части рядом.
- Чтение и извлечение выполняются вне главного потока: окно остаётся отзывчивым, показывает индикатор текущей операции и даёт отменить её. Отмена завершает дочерний процесс `7zz`; уже записанные файлы не удаляются.

## Задача первого MVP

1. Открыть обычный архив в Quick Look Finder.
2. Показать дерево файлов и папок.
3. Позволить отметить отдельные элементы.
4. Распаковать выбранное в указанную папку без перезаписи существующих файлов по умолчанию.
5. Передать парольный или многотомный архив в служебное окно Зипчика через «Открыть с помощью».

## Техническое решение

- UI: нативное приложение macOS на SwiftUI.
- Движок основного приложения: неизменённый `7zz` 26.02 из пакета 7-Zip, копируемый в bundle при сборке и запускаемый отдельным процессом.
- Роль `7zz`: список записей, проверка архива и извлечение только явно выбранных путей.
- Finder: приложение регистрирует поддерживаемые типы архивов в `Info.plist` и содержит `ZIPQuickLook.appex`.
- Движок Quick Look: системный `/usr/lib/libarchive.2.dylib`, вызываемый внутри процесса расширения через небольшой C-мост.

## Quick Look

Расширение Quick Look показывает список обычных файлов с чекбоксами. Кнопка «Извлечь выбранное…» открывает прикреплённую системную панель выбора папки, после чего расширение самостоятельно извлекает отмеченные файлы через libarchive. В Finder реально проверены ZIP, 7z, RAR5 и `.tar.gz`; также заявлены GZIP, BZIP2, XZ, Zstandard, ISO, CAB, CPIO, XAR, ARJ и LHA/LZH — в пределах возможностей системного libarchive.

Такое разделение нужно из-за песочницы расширений macOS: Quick Look не может запускать вложенный `7zz` и не может передать команду основному приложению через Launch Services. Внутрипроцессный libarchive не требует запуска дочернего процесса и остаётся в разрешённой модели Quick Look.

Расширение зарегистрировано в PluginKit и полностью проверено в Finder на `.7z`: отображаются заголовок, список, чекбокс и кнопка; прикреплённая панель выбора папки открывается; отмеченный файл извлекается с совпадающим SHA-256. Для публикации вне этого Mac всё равно понадобится штатная подпись Apple Development или Developer ID и обычная процедура notarization.

## Открытие архивов

Зипчик не назначает себя приложением по умолчанию. Обычные архивы открываются пробелом в Finder; для сложного архива выберите «Открыть с помощью → Зипчик». Регистрация UTI остаётся только затем, чтобы Finder знал, что Зипчик умеет открыть поддерживаемые архивы.

## Лицензирование движков

Для MVP допустима поставка неизменённого бинарника `7zz` как отдельного процесса: собственное SwiftUI-приложение не линкуется с LGPL-кодом и не становится LGPL из-за вызова команды.

Перед распространением приложения обязательны:

1. положить в bundle неизменённый файл лицензии 7-Zip `license.txt`;
2. в разделе «Лицензии» указать использование 7-Zip, GNU LGPL-2.1-or-later и ссылку на исходный код `https://www.7-zip.org/`;
3. сохранить уведомления BSD-2-Clause/BSD-3-Clause, включённые в `license.txt`;
4. не модифицировать unRAR-код и не использовать его для реализации RAR-архивов.

Если когда-либо вместо запуска `7zz` будет встроена или изменена библиотека 7-Zip, потребуется отдельный LGPL-compliance проход: исходники и изменения LGPL-части, возможность заменить библиотеку и проверка условий релиза.

Quick Look линкуется с системной библиотекой libarchive. Основной код libarchive использует permissive BSD-style условия, а upstream `COPYING` отдельно перечисляет исключения для отдельных файлов. Полная копия актуального `COPYING` включена в ресурсы приложения и расширения. Код проекта не содержит исходников libarchive и не встраивает его отдельную копию.

## Форматы MVP

Основная цель: ZIP, 7z, TAR, GZIP, BZIP2, XZ, RAR и их распространённые варианты — в пределах фактически поддерживаемых установленной версией `7zz` форматов.

Формат не обещается пользователю до проверки конкретным движком. Парольные 7z и многотомные 7z-наборы проверены в окне приложения. Повреждённые архивы и специальные атрибуты файлов — отдельные сценарии тестирования.

## Границы безопасности

- Никогда не извлекать путь, выходящий за выбранную папку назначения.
- Не включать авто-перезапись файлов.
- В Quick Look извлекать только обычные файлы; пропускать каталоги, симлинки и hard link entries.
- Создавать вложенные каталоги через `openat`/`mkdirat` с `O_NOFOLLOW`, чтобы существующий симлинк не мог вывести запись за пределы выбранной папки.
- Сначала показывать список, затем выполнять извлечение.
- Перед запуском внешней команды проверять, что архив и папка назначения существуют.

## Ближайший шаг

Собрать RAR с паролем и несколькими томами для отдельной runtime-проверки; notarization отложена по решению пользователя.
